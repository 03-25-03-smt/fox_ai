## Интеграция с fish_helper (аквариум брата) — после P100

Сейчас fish_helper работает отдельно на Railway. Боты Telegram не видят друг друга,
поэтому связь — через HTTP внутри docker-сети.

1. Перенести fish_helper с Railway в `docker-compose.yml` fox_ai (перенести базу через `/backup`).
2. В fox_ai — внутренний API с токеном (только docker-сеть): анализ фото, советы, разбор статистики.
3. В fish_helper:
   - фотоотчёт по расписанию (например, после подмены воды) → анализ vision-моделью
     (мутность, водоросли, растения, поведение рыб);
   - фото тест-полосок (pH, NO₂, NO₃, KH, GH) → запись в историю и тенденции;
   - недельные советы по пропускам и причинам «не могу»;
   - вопросы брата в режиме «аквариумист»; тревога владельцу при подозрительном фото.
4. Ограничения: 7b-vision не ставит точных диагнозов — формулировать как «похоже на…, проверь…»;
   тест-полоски снимать рядом со шкалой.
